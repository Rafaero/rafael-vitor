# Rafael Vitor — Static Site

A clean, responsive single-page profile site (English) with WhatsApp CTA.
Built for GitHub Pages.

## Quick start
1. Create a new **public** repository on GitHub (e.g., `rafael-vitor`).
2. Upload the files in this folder to the repository root.
3. In the repo settings, enable **Pages** -> Source: `deploy from a branch` -> Branch: `main` (or `master`) `/root`.
4. Replace `<your-username>` and `<your-repo>` in `index.html` OpenGraph fields with your real values.
5. (Optional) Add a `CNAME` file with your custom domain.
